BlockStack Launcher

A lightweight, open-source, non-premium Minecraft launcher for Linux — written entirely in Python. No bloat. No Electron. Just the game.

Get it on GitHub How to run

Features

Everything you need, nothing you don't.

🧱

Pure Python

Bypasses heavy bloatware. The launcher runs entirely on Python — tiny footprint, fast startup.

📁

Isolated Instances

Full support for separate instances (folders). Keep worlds and mods perfectly organized.

⚡

Multi-threaded Assets

Concurrent downloads of libraries and assets from Mojang's official servers for faster installs.

🖥️

Simple Tkinter GUI

A clean, tabbed interface for profiles, versions, RAM, and game directories. No clutter.

Install & Run

Linux only — three steps to launch.

  1. Install dependencies — Python 3 and Tkinter: sudo apt install python3-tk
  2. Clone the repo: git clone https://github.com/fitzypopper/BlockStack-Launcher
  3. Launch the menu: python3 menu.py
